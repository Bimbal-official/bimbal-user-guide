# Bimbal User Guide

This repository contains the user guide and the release notes of
Bimbal, software for construction companies.

## How it works

-   Each branch documents one version, for example `19.0`.
-   Each page describes one topic, as Bimbal behaves in that version.
-   Screenshots and animations use fictitious data.

The user guide explains how to use Bimbal.

`release_notes/` lists, for each release, the changes that affect
users: new features, improvements, changed behavior, removed features,
and actions required after an update. Release notes are not
exhaustive and must not be used as a technical or development
reference.

## Limits

-   The user guide is provided as is. It may not reflect the latest
    version of Bimbal, or the configuration of a specific database.
-   Menu paths describe the default menus, which an administrator may
    have customized.
-   It does not replace support.

For any question or doubt, create a support ticket:
https://www.bimbal.com/help
