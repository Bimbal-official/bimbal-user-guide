# Bimbal Development Instructions

Before performing any task in this repository:

1.  Locate the repository named `bimbal-dev-guidelines` that is mounted
    or checked out in the same development environment/workspace.
2.  Read and follow its `AGENTS.md`.
3.  Read every specialized guideline referenced by that `AGENTS.md` that
    applies to the task.

The locally available `bimbal-dev-guidelines` repository is the
preferred source. Its canonical GitHub repository is
`Bimbal-official/bimbal-dev-guidelines`.

The guidelines are mandatory.

Unless the task explicitly concerns the guidelines themselves, treat
`bimbal-dev-guidelines` as read-only.

Paths in its documents are relative to the root of
`bimbal-dev-guidelines`.

If no local copy is available, make a shallow clone of the `main`
branch of `Bimbal-official/bimbal-dev-guidelines`, outside any other
repository, and use it read-only. If this fails, **STOP before
analyzing, modifying, generating, committing, or pushing code** and
report that limitation.

Do not proceed using remembered or copied development rules.
